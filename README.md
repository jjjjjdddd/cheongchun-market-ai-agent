# 청춘마켓 안심거래 도우미

청춘마켓 팀 프로젝트를 진행한 뒤 상품 가격과 거래 전 확인할 내용을 안내하는 기능도 만들어 보고 싶어 AI의 도움을 받아 진행한 개인 프로젝트입니다.

코드 작성과 수정에는 AI의 도움을 받았고 저는 만들고 싶은 기능을 설명한 뒤 실행 결과를 확인하면서 잘못된 부분을 찾았습니다.

## 담당 업무

- 상품 정보를 바탕으로 거래 전 확인할 내용을 안내해 달라고 AI에게 기능 방향 설명
- AI가 만든 코드를 실행하고 질문을 입력해 결과 확인
- 질문과 다른 상품이 검색되는 오류를 발견해 수정 요청
- 수정 후 같은 질문을 다시 입력해 안내가 달라졌는지 확인

## 직접 발견한 오류

실행 결과를 확인하다가 에어팟 프로 2를 질문했는데 갤럭시 버즈2가 검색되는 문제를 발견 후 다른 제품의 정보를 안내하면 가격을 잘못 판단할 수 있어 이 상황을 AI에게 설명하고 수정을 요청

수정 후 같은 질문을 다시 입력했을 때는 다른 제품 정보 대신 등록된 데이터가 없다는 안내가 나오는 것을 확인

## 현재 프로젝트 범위

등록된 데모 상품 정보를 바탕으로 질문에 답하는 연습용 서비스이며 실제 거래 데이터나 실시간 시세와는 연결하지 않았고 상품 정보가 없는 질문에는 데이터 부족 안내가 나오도록 했지만 전체 오류율이나 정확도를 따로 측정하지는 않았습니다.

## 이번 경험에서 배운 점 & 포부

AI가 만든 결과도 직접 확인하면 예상과 다르게 동작하는 부분을 찾을 수 있다는 점을 배웠습니다. 이번 프로젝트에서 제가 직접 한 일은 기능 방향을 설명하고 오류를 찾아 수정을 요청한 뒤 결과를 다시 확인하는 과정에서 AI가 만든 결과도 그래도 받아들이보다 직접 확인해 봐야 한다는 점을 배웠습니다. 이 경험을 바탕으로 메타로직컨설팅에서도 자료 조사와 사례 비교 업무를 배우며 찾은 내용이 원문과 맞는지 확인하고 이해되지 않은 부분은 질문하면서 팀이 활용하기 쉬운 자료로 정리하고 싶습니다.
