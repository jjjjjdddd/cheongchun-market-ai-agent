# 청춘마켓 안심거래 도우미

대학생 중고거래 서비스 **청춘마켓**을 개발하면서 상품을 찾는 기능 외에도 가격이나 거래 전 확인할 내용을 안내하는 기능이 있으면 좋겠다고 생각했습니다. 그래서 AI의 도움을 받아 등록된 상품 정보를 검색하고 그 내용을 바탕으로 거래 정보를 안내하는 개인 프로젝트를 진행했습니다.

AI가 만든 코드를 실행해 결과를 확인하던 중 **에어팟 프로 2를 질문했는데 갤럭시 버즈2가 검색되는 오류를 발견했습니다.** 이 문제를 AI에게 설명하고 수정을 요청한 뒤 같은 질문을 다시 입력해 봤습니다. 수정 후에는 다른 제품의 가격을 안내하는 대신 등록된 데이터가 없다는 안내가 나오는 것을 확인했습니다.

## 프로젝트 개요와 담당 범위

- 기간: 2026.08
- 형태: 개인 프로젝트
- 제가 한 일: 만들고 싶은 기능을 설명하고 AI가 만든 코드를 실행해 결과 확인
- 오류 확인: 에어팟 질문에 다른 상품이 검색되는 문제를 발견해 수정 요청
- 개발 방식: 기능 구현과 코드 수정에는 AI의 도움을 받았고 실행 결과와 수정 후 동작은 제가 확인했습니다.

[청춘마켓 팀 프로젝트 자료](https://github.com/jjjjjdddd/portfolio)는 별도 저장소에서 확인할 수 있으며 여기에는 그 이후 개인적으로 진행한 거래 정보 안내 프로젝트를 정리했습니다.

## 해결하려고 한 문제

상품 가격을 판단하려면 상태나 출시 연도와 구성품도 함께 확인해야 하기 때문에 AI의 도움을 받아 이 정보를 CSV로 정리하고 질문에 맞는 상품을 검색하도록 만들었습니다.

그런데 처음에는 검색 결과를 그대로 답변에 사용하다 보니 에어팟 질문에 갤럭시 버즈 정보가 나오는 문제가 있었습니다. 같은 이어폰이어도 다른 제품의 가격을 참고하게 될 수 있어 질문한 상품과 검색된 상품이 맞는지 확인하도록 수정을 요청했습니다.

## 오매칭 사례와 개선

| 확인한 내용 | 수정 전 | 수정 후 |
|---|---|---|
| 질문 | CSV에 없는 에어팟 프로 2 | 같은 미등록 상품 질문 |
| 검색 근거 | 같은 이어폰 카테고리의 갤럭시 버즈2가 검색됨 | 등록 제품군과 일치하지 않으면 빈 검색 결과 반환 |
| 답변 처리 | 다른 제품의 정보가 가격 안내 근거가 될 수 있음 | 데이터 부족 안내와 추가 확인 항목 제공 |
| LLM 호출 | 검색 근거를 전달해 답변을 생성하는 구조 | 근거가 없으면 LLM을 호출하지 않음 |

AI에게 오류를 설명한 뒤 질문과 검색 결과의 제품군을 확인하는 절차를 추가했습니다.

1. 질문에서 공백을 제거한 뒤 등록 제품군이 포함됐는지 확인합니다.
2. 벡터 검색 결과에서도 같은 제품군의 문서만 남깁니다.

현재 코드는 아이패드와 맥북 그리고 갤럭시버즈와 닌텐도스위치의 4개 제품군을 확인하도록 되어 있습니다. 일치하는 상품 정보가 없으면 `generate` 단계에서 데이터 부족 안내를 보내고 `ChatOllama`는 호출하지 않는 방식입니다.

에어팟 질문에 다른 제품이 검색되던 사례는 수정 후 다시 확인했지만 전체 검색 정확도나 오류 감소율을 따로 측정하지는 않았습니다.

## 주요 기능

- CSV 상품 데이터를 문서로 변환하고 Chroma Vector DB에 저장
- 사용자 질문에 관련된 상품 문서 검색
- 질문의 제품군과 검색 결과의 제품군 확인
- Ollama 로컬 LLM을 이용한 데이터 기반 거래 안내
- 답변에 사용한 상품 정보를 화면에서 확인
- 상품 근거가 없는 경우 모델명과 상태 및 구성품 등 추가 확인 항목 안내
- 빈 질문 입력 시 안내 표시

## 데이터 구성

`data/products.csv`에는 4개 제품군의 데모 상품 정보 5개를 넣었으며 아이패드는 상태가 다른 상품 2개로 구성했습니다.

| 항목 | 컬럼명 | 용도 |
|---|---|---|
| 상품명 | `product_name` | 질문 대상과 검색 결과 비교 |
| 카테고리 | `category` | 상품 종류 확인 |
| 상태 | `condition` | 상품 상태 확인 |
| 출시 연도 | `year` | 가격 판단 조건 확인 |
| 정가 | `original_price` | 참고 정보 |
| 판매희망가 | `asking_price` | 등록 상품의 제시 가격 |
| 참고 시세 범위 | `market_range` | 데모 데이터에 기재한 비교 범위 |
| 거래 지역 | `location` | 거래 조건 확인 |
| 특이사항 | `note` | 구성품과 상품 상태 등 추가 정보 |

가격과 참고 시세는 데모 데이터에 적힌 값을 사용하므로 실제 거래에 참고하려면 최신 가격과 상품 상태를 별도로 확인해야 합니다.

## 처리 흐름

| 순서 | 처리 |
|---|---|
| 1 | Streamlit 화면에서 사용자 질문 입력 |
| 2 | 등록 제품군 포함 여부 확인 |
| 3 | 등록 제품군이면 Chroma에서 관련 문서 최대 3개 검색 |
| 4 | 같은 제품군의 문서만 근거로 사용 |
| 5 | 근거가 있으면 Ollama로 거래 안내 생성 |
| 6 | 근거가 없으면 LLM 호출 없이 데이터 부족 안내 반환 |
| 7 | 답변과 사용한 상품 정보 표시 |

검색과 답변 생성은 LangGraph의 `retrieve`와 `generate` 노드로 연결되어 있으며 정해진 순서에 따라 처리하는 RAG 워크플로입니다.

## 사용 기술

| 기술 | 적용한 기능 |
|---|---|
| Python과 pandas | CSV 읽기와 상품 데이터 처리 |
| Chroma | 상품 문서 저장과 유사도 검색 |
| nomic-embed-text | 상품 문서와 질문 임베딩 |
| LangChain | 문서와 Ollama 모델 연동 |
| LangGraph | 검색과 답변 생성 단계 연결 |
| Ollama와 Qwen2.5 3B | 로컬 답변 생성 |
| Streamlit | 질문 입력과 답변 및 근거 표시 |

## 실행 방법

실행하려면 Python 3과 [Ollama](https://ollama.com/download)를 준비하고 모델과 패키지를 먼저 설치해야 합니다. 다운로드할 때는 인터넷 연결이 필요하며 앱을 사용하는 동안에는 Ollama도 실행해 두어야 합니다.

### 1. 저장소 받기

```bash
git clone https://github.com/jjjjjdddd/cheongchun-market-ai-agent.git
cd cheongchun-market-ai-agent
```

### 2. 가상환경과 패키지 설치

아래는 macOS와 Linux 기준입니다.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

### 3. 사용할 모델 준비

```bash
ollama pull qwen2.5:3b
ollama pull nomic-embed-text
```

Ollama가 실행되지 않았다면 앱을 실행하거나 별도 터미널에서 `ollama serve`를 실행합니다.

### 4. 앱 실행

```bash
python -m streamlit run app.py
```

앱을 실행한 뒤 터미널에 표시되는 주소로 접속하면 됩니다. 기본 주소는 `http://localhost:8501`이며 처음에는 CSV 데이터를 검색할 수 있도록 준비하는 과정이 있어 실행 환경에 따라 시간이 걸릴 수 있습니다.

## 확인할 수 있는 입력 사례

| 입력 | 확인할 동작 |
|---|---|
| 아이패드 9세대 64GB를 28만원에 사도 될까요? | 같은 제품군의 상품을 검색하고 답변과 근거 표시 |
| 맥북 에어 M1을 살 때 확인할 점은 무엇인가요? | 등록된 상품 정보를 근거로 확인사항 안내 |
| 에어팟 프로 2의 가격을 알려줘 | 데이터 부족 안내와 추가 확인 항목 표시 |
| 공백만 입력 | 질문 입력 안내 표시 |

등록된 상품의 답변은 모델 실행 결과에 따라 달라질 수 있지만 데이터가 없을 때는 코드에 정해 둔 안내 문구가 나옵니다.

## 현재 한계와 다음 개선

- 현재 제품군 목록은 코드에 직접 적어 둔 상태라 상품이 늘어나면 CSV와 목록을 함께 관리할 수 있도록 바꾸고 싶습니다.
- 제품군 단위로 확인하기 때문에 같은 제품의 세대나 용량까지 정확히 구분하는 부분은 더 개선해야 합니다.
- 아직 데모 상품 5개로 동작하며 실제 상품 등록 데이터와는 연결하지 않았습니다.
- 등록된 정보만 사용하도록 답변 규칙을 넣었지만 모델이 부정확하게 답할 가능성은 남아 있습니다.
- 자동 테스트나 정확도 평가도 아직 없어 앞으로 질문별로 어떤 근거를 사용하고 어떻게 답하는지 확인할 사례를 늘리고 싶습니다.

## 프로젝트를 통해 배운 점

이번 프로젝트에서는 AI가 만든 기능을 직접 실행해 보면서 검색 결과가 나와도 질문에 맞지 않는 정보일 수 있다는 점을 알게 됐습니다. 에어팟 질문에 버즈가 검색되는 문제를 발견하고 수정을 요청하는 과정에서 결과를 그대로 받아들이기보다 질문한 내용과 맞는지 확인하는 것이 중요하다고 느꼈습니다.

앞으로 새로운 기술을 활용할 때도 직접 실행해 결과를 확인하고 예상과 다른 부분이 있으면 구체적으로 설명해 개선하는 방식으로 배우고 싶습니다.
